# 从语音输入到语音遥控

声控台包含三个逐步交付的方向：输入文字、操作桌面、从个人使用经验中改进。v0.1.0 先交付 Linux 听写。

## 语音遥控

前身项目的 Windows 版本已完成系统资源诊断、打开任务管理器，以及任务状态、取消、焦点保护和操作记录基础设施。独立实验分支已有受管浏览器、页面观察和媒体工作流代码；真实浏览器播放闭环仍需完成，尚未随本仓库发布。

下一段可验收的任务是：语音发出一个明确的浏览器媒体请求，完成搜索、选择和播放；再次观察播放器状态，支持中途停止和人工接管。存在多个结果时由用户选择。用固定测试页面和公开媒体进行验证，再移植到新项目。

如果使用实体语音遥控器，先把 USB/蓝牙按键映射为开始、结束、取消。音频设备选择和按钮传输分开处理；待确定硬件型号后验证长按、重复按键、断连和重连。

## Activity Log 的用途

活动记录作为可选的本地经验来源：

1. 统计录制覆盖、数据保留窗口、语音链路和人工纠正样本。
2. 将连续事件归并为任务片段，保存开始条件、执行步骤、结束证据和失败原因。
3. 从重复任务生成候选操作流程，先由用户确认，再在隔离环境回放。
4. 按日期划分开发与验证样本；统计成功率、误执行、取消和恢复情况。

原始键鼠数量不能直接表示任务数量；人工纠正也需要检查是否指向同一次语音输出。第一阶段重点建立任务样本和评测，再根据真实失败决定是否微调模型。

ActivityRecorder 独立安装、独立存储。公开代码使用合成或经过专门整理的样本；私人录音、截图、会话正文和密钥留在用户设备。
